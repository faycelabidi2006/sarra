# إعداد Supabase لأعضاء FamilyTV (حساب واحد = جهاز واحد)

1. في مشروع Supabase: SQL Editor > الصق `setup.sql` كاملاً > Run.
2. شغّل مرة واحدة سطر `insert into public.fm_admin ...` الموجود معلّقاً في آخر الملف، بعد وضع **سر مالك** طويل عشوائي (24 حرفاً أو أكثر).
   السر لا يوضع في الكود. تلصقه في التطبيق من: Settings > Control panel > Admin secret.
3. من Project Settings > API انسخ **Project URL** و **anon / publishable key**، وضعهما في
   `app/src/main/java/com/example/familytv/data/Server.kt` (`SbConfig.URL` و`SbConfig.ANON_KEY`) ثم ابنِ التطبيق.
   المفتاح العام ليس سراً. لا تضع `service_role` في التطبيق أبداً.

## كيف يعمل
- العضو يدخل بالاسم وكلمة السر. أول جهاز يدخل **يرتبط به الحساب**.
- أي جهاز آخر بنفس البيانات يُرفض برسالة "linked to another device".
- لنقل العضو إلى جهاز جديد: Control panel > Reset device. الجهاز القديم يُقطع خلال دقيقة تقريباً.
- التطبيق يرسل نبضة كل دقيقة: يتحقق الخادم من الجلسة والاشتراك ويسجّل "متصل الآن" وما يشاهده ومدة المشاهدة.
- إيقاف العضو أو حذفه أو انتهاء اشتراكه يُخرجه من التطبيق خلال دقيقة.
- كلمات السر تُخزَّن مشفّرة (bcrypt) على الخادم، و5 محاولات خاطئة تقفل الحساب 5 دقائق.
